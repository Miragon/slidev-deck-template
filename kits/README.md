# Kits

One folder per thing you deliver in the Miragon brand. Each kit holds its npm packages under `packages/` and a reference project you can copy from.

| Kit | For | Reference project |
| --- | --- | --- |
| [slidev](slidev/) | Talk, workshop and sales decks | [`slidev/deck/`](slidev/deck/), live at [slidev-template.netlify.app](https://slidev-template.netlify.app) |
| [hub](hub/) | A training site with a sign-in around the deck | scaffolded with `--hub`, see [hub](hub/) |
| [docs](docs/) | The docs site of a Miragon tool | [`docs/example/`](docs/example/) |

Where to start is in the [README at the repository root](../README.md).
